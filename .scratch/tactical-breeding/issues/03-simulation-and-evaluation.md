# Define the first simulation and evaluation experiment

Labels: wayfinder:grilling
Type: grilling
Mode: HITL
Status: open
Blocked by: 01, 02

## Question

Given the newly agreed combat and creature models, what smallest experiment can evaluate directed tactical breeding, useful variation, diverse exceptional outcomes, and meaningful counterability against the [spec](../spec.md)?

Define the concrete generation/expression/inheritance candidate to test, how a player can influence breeding, and what uncertainty remains. Select these for the tactical question rather than inheriting a former genome representation or generic lab framework. Split additional design tickets out of this question if a candidate needs separate decisions before an experiment can be bounded.

## Completion

- Bound the first tactical problem, creature/mechanic vocabulary, and proposed breeding candidate; distinguish hypotheses from requirements.
- Define viability, exceptional strength, counterability, and evidence of directed customization operationally, without reducing all goals to one score.
- Specify encounter and squad coverage, agent limitations, reproducible inputs/rule versions, outcome measurements, execution-validity checks, and representative human playtests.
- Separate outcome frequency from matchup performance. Explain what evidence would reveal universal dominance or an evaluator blind spot.
- Record acceptance criteria, failure/revision criteria, and only the tooling needed for this experiment. Treat the spec's suggested several-answers-to-one-problem experiment as a candidate, not a preselected plan.
- Update the spec and identify any further design or implementation tickets explicitly; resolving this ticket does not itself authorize implementation.

Do not expand the first experiment into a player population, economy, acquisition campaign, or long-term metagame simulation. No trained agent, learned evaluator, framework, UI layout, or suite architecture is preselected.
